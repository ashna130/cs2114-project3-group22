# Fast Food Order Simulator

CS 2114 Project 3, Group 22

Tracks fast food orders in a first in, first out line. Users can add random orders, see the current orders, and complete or cancel the order at the front.

## Classes

- `QueueInterface`, `LinkedQueue`: the queue
- `Order`: one customer's order
- `OrderMaker`: makes random orders
- `OrderTracker`: model, holds the line
- `OrderView`: view, the menu
- `ProjectRunner`: starts the program

## Run

Import into Eclipse, then run `ProjectRunner`.
